# 原始过程记录

首次分析本题前登记本题根和主会话。子 Agent 启动、重试、替换、恢复均登记真实实例 ID、角色、原生会话 ID（若可获得）和派工文件。无法获得的字段明确写不可获得，不编造。

保留输入、实际提示、工具调用与返回、失败、重试、未采用方案、代码差异、测试输出，使用运行器原生记录/导出。事件日志和角色交接是索引，不能替代原始记录，不生成伪原始对话。

若 `$CODEX_HOME/sessions`（未设置时 `C:\Users\22580\.codex\sessions`）有原生 JSONL，用 `scripts/snapshot_traces.py --root 本题目录` 复制状态中明确登记的 UUID 对应文件。只匹配这些会话，不导出其他对话。存储方式不同或 ID 不匹配时使用运行器实际导出能力并登记路径；脚本返回缺失项时保留 `record_gaps`，不能宣称记录完整。

快照按时间分目录保存，含 SHA-256 和源路径。活跃会话拷贝只是当时快照，末行可能未写完；不宣称包含拷贝后的内容。阶段结束、等待用户或中断前快照；正式冻结时结束修改及子任务后导出最终版本。

只保存实际使用的配置；配置更新时在本题 system-config 增加版本、说明原因，不覆盖旧快照。配置不能含凭据。日志仅本地保存，对外提交前按赛事规则脱敏并保留说明，不擅自上传。

人工操作如登录和引导如实登记；没有人工改代码则注明。官方 trace-index 引用这些原始文件和源码版本，不补造缺失过程。
