- 实现内容：
  - 新增迷你播放器 `MiniPlayer.ets`，放在首页、搜索结果页、歌单页底部，显示封面、歌名、歌手、当前时间 `m:ss` 和播放/暂停按钮。点封面或栏体进入播放页；点按钮只切换播放状态。

1. 向下箭头放在顶部正中，不在左上角：放左上角会压在下层结果页的返回按钮上，连点时会多退一层。

## 已知问题

- 本地 API 服务 `/search` 中文关键词返回异常结果（如搜"晴天"得到"93"），`/cloudsearch` 正常。这是服务端问题，与应用代码无关。自测因此改为从结果中动态选一首可完整播放、时长不少于 2 分钟的歌。
- 本地 API 对同一 URL 有 120 秒缓存，期间的重复请求不进日志。请求计数用例会先等缓存过期。
- 基线原有、本题未改的问题：音频加载失败时仍显示"播放中"；搜索结果为空时一直转圈；两个 HTTP 请求方法都开着 `usingCache`。
- 模拟器音频播放依赖宿主网络：2026-10-18 因模拟器 DNS 失败无法播放，2026-10-19 恢复，恢复原因未确认。
