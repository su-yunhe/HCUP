# WebDAV 恢复取消状态

## 场景一：取消会关闭确认弹窗

### 场景概述

用户点击「从云端恢复」打开第一层确认弹窗后，如果点击「取消」，弹窗必须关闭，页面回到 WebDAV 设置操作区。

### 操作步骤与预期结果

1. 用户进入 WebDAV 配置页，并点击「从云端恢复」。
2. 页面显示恢复确认弹窗。
3. 用户点击「取消」。
4. 确认弹窗关闭，用户回到 WebDAV 配置页。

## 场景二：取消后恢复入口仍可继续使用

### 场景概述

取消恢复操作后，「从云端恢复」按钮仍须可用。用户应能再次点击该按钮，打开恢复确认弹窗。

### 操作步骤与预期结果

1. 用户打开「从云端恢复」确认弹窗。
2. 用户点击「取消」关闭弹窗。
3. WebDAV 配置页仍显示可用的「从云端恢复」按钮。
4. 用户再次点击该按钮时，应用能够重新打开确认弹窗。

## 场景三：反复取消仍不产生 WebDAV 请求

### 场景概述

用户取消恢复后再次打开确认弹窗，只要没有明确点击「继续」，应用仍不得向 WebDAV 服务端发送请求。

### 操作步骤与预期结果

1. 用户点击「从云端恢复」打开确认弹窗。
2. 用户点击「取消」关闭弹窗。
3. 用户再次点击「从云端恢复」打开确认弹窗。
4. 在用户未点击「继续」前，测试环境不应观察到任何 WebDAV 请求。
