# WebDAV 手动同步加载反馈

## 场景一：手动同步显示加载指示器

### 场景概述

用户点击「立即同步」后，WebDAV 配置页必须进入忙碌状态，并在后端同步操作运行期间渲染 ArkUI `LoadingProgress` 加载指示器。

### 操作步骤与预期结果

1. 用户进入 WebDAV 配置页，并填写可访问的 WebDAV 配置。
2. 用户点击「立即同步」按钮。
3. 页面进入同步忙碌状态。
4. 页面显示 ArkUI `LoadingProgress` 加载指示器。

## 场景二：同步加载状态与实际同步操作保持一致

### 场景概述

同一个忙碌状态必须对应真实的 WebDAV 同步流程。只有在能够观察到后端请求时，加载状态 才被认为有效。

### 操作步骤与预期结果

1. 用户点击「立即同步」按钮。
2. 页面显示加载指示器。
3. 应用启动 WebDAV 同步流程。
4. 测试环境能够观察到应用向配置的 WebDAV 服务端发送请求。

## 场景三：显示加载状态的同时须执行同步请求

### 场景概述

「立即同步」不能只改变 UI 状态。同步操作必须向配置的 WebDAV 端点发送请求，加载反馈必须和真实的后端同步请求绑定。

### 操作步骤与预期结果

1. 用户点击「立即同步」。
2. 页面展示同步中的加载反馈。
3. 应用向配置的 WebDAV 服务端发起请求。
4. 如果只有加载状态而没有后端请求，则该功能点不满足要求。
