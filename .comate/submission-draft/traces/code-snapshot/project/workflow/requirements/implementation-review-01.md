## 4. U2/U4：本题证据与来源决策

**外部所需最小输入**：各提供商合法的 SDK/启动方式和已注册应用配置（与本应用包名/签名/回调匹配）、可用的授权回调条件；微信确切凭据映射和支付宝认证契约；如要验证登录成功，还需可用后端、账号/设备条件及成功落点口径。Spec 只明确真实流程/可选交互，没有明文要求本题补齐所有成功后的用户业务。

可先把图标点击接到清楚、可恢复的接入边界；配置缺失时诚实提示、不写 Token、不发伪造认证请求。该分支可单测/设备验证反馈与恢复，但 B9–B11 仍是外部条件未满足、尚未通过。未来取得真实授权条件后，按 D3 展开取消、拒绝、超时、失败、晚/重复回调和重入测试；HTTP loading 必须绑定真实请求，不能把配置检查冒充授权/请求。
