# 底部导航栏（首页/分类/购物车/我的）

## 场景一

### 场景概述

用户进入应用后，看到底部导航栏显示四个标签：首页、分类、购物车、我的。用户点击不同的标签，页面切换到对应内容区域，并触发 Lottie 动画效果高亮选中项。

### 操作步骤与预期结果

1. 用户启动应用，进入主页面，底部导航栏显示"首页"、"分类"、"购物车"、"我的"四个标签。
2. 默认选中"首页"标签，首页内容区域显示在上方。
3. 用户点击"分类"标签，页面内容区域切换为分类页面。
4. 底部"分类"标签图标触发 Lottie 动画，图标颜色变为黑色，其余标签图标重置为灰色。
5. 用户点击"购物车"标签，页面内容切换为购物车页面，购物车图标播放动画。

## 场景二

### 场景概述

用户通过左右滑动屏幕内容区域来切换底部导航栏对应的标签页，底部导航栏随滑动联动更新选中状态并触发相应的 Lottie 动画。

### 操作步骤与预期结果

1. 用户在"首页"内容区域向左滑动，页面滑动到"分类"页面。
2. 底部导航栏"分类"标签自动高亮，对应图标播放动画。
3. 用户继续向左滑动，页面切换到"购物车"。
4. 用户点击底部"我的"标签，内容区域跳转到"我的"页面，图标动画播放。

## 场景三

### 场景概述

用户首次进入应用，底部导航栏"首页"标签处于初始选中状态，对应 Lottie 动画自动播放；当用户回到该标签时，动画重新播放一次以提示当前位置。

### 操作步骤与预期结果

1. 应用启动，主页面初始化完成，底部"首页"标签图标自动播放 Lottie 动画。
2. 用户点击"我的"标签切换到我的页面，"我的"图标播放动画，"首页"图标回到第一帧静止。
3. 用户点击"首页"标签返回，首页图标重新播放动画。
4. 内容区域显示首页内容，"首页"标签文字颜色变为黑色。

## 场景四

### 场景概述

用户在"首页"内容区域向下浏览了一段距离（例如已经滚动过"限时精选""推荐商品"区域），此时再次点击底部导航栏中已经处于选中状态的"首页"标签，首页内容区域会自动滚动回到顶部；这次点击不会触发页面切换（本来就在首页），也不会额外重播首页图标的 Lottie 动画。

### 操作步骤与预期结果

1. 用户当前位于"首页"，底部导航栏的"首页"标签已选中，向下滑动内容区域，顶部的优惠券"领取"入口已经滚出可视区域。
2. 用户再次点击底部导航栏的"首页"标签（该标签已处于选中状态，不是从其他标签切回）。
3. 首页内容区域自动滚动回顶部，顶部优惠券"领取"入口重新出现在可视区域内。
4. 底部"首页"标签保持选中状态，不触发页面切换动画。
