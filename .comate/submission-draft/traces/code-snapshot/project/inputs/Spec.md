# 登录主页面与手机号登录入口

## 场景一

### 场景概述

用户进入登录主页面，看到应用 Logo 图标、"手机号登录"主按钮和"账号密码登录"次级按钮，点击"手机号登录"按钮后跳转到短信验证码登录页面。

### 操作步骤与预期结果

1. 用户点击"我的"页面中的登录入口，进入登录主页面。
2. 页面顶部居中显示应用 Logo 图标（尺寸 120）。
3. Logo 下方有"手机号登录"主按钮（实心圆角样式）和"账号密码登录"次级按钮（空心圆角样式）。
4. 用户点击"手机号登录"按钮，跳转到手机短信验证码登录页面。
5. 用户点击"账号密码登录"按钮，跳转到账号密码登录页面。

## 场景二

### 场景概述

用户在登录主页面查看第三方登录入口（微信、QQ、支付宝），可以选择第三方账号快速登录；页面底部展示用户协议和隐私政策，用户可点击查看详情。

### 操作步骤与预期结果

1. 登录按钮下方显示"其他登录方式"提示文字。
2. 文字下方以均匀间隔排列三个第三方登录图标：微信、QQ、支付宝。
3. 每个图标下方有对应的文字说明。
4. 用户点击微信图标，触发微信登录流程。
5. 页面最底部展示"登录即代表同意《用户协议》和《隐私政策》"的文案，链接文字为主题色。

## 场景三

### 场景概述

在不同屏幕尺寸设备上，登录主页面的按钮区域宽度自适应调整，平板端按钮区域宽度缩小为页面的 70%，大屏设备缩小为 60%，保持居中显示。

### 操作步骤与预期结果

1. 用户在手机设备上打开登录页面，按钮区域宽度为屏幕全宽。
2. 在平板设备上打开登录页面，按钮区域宽度缩小至页面宽度的 70%，居中对齐。
3. 在更宽的设备上，按钮区域进一步缩小至页面宽度的 60%。
4. 所有尺寸下第三方登录图标均以均匀间距在按钮区域内排列。
