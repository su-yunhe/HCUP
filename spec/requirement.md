# WebDAV 同步进度提示与实际操作保持一致

## 场景一：手动同步显示加载指示器

### 场景概述

用户点击「立即同步」后，WebDAV 配置页必须在同步运行期间渲染 ArkUI `LoadingProgress` 加载指示器。

### 操作步骤与预期结果

1. 用户进入 WebDAV 配置页，并填写可访问的 WebDAV 配置。
2. 用户点击「立即同步」按钮。
3. 页面进入同步忙碌状态。
4. 页面显示 ArkUI `LoadingProgress` 加载指示器。

## 场景二：手动同步向 WebDAV 服务端发送请求

### 场景概述

加载指示器必须和真实的 WebDAV 操作绑定。同步流程必须在忙碌状态可见时向配置的端点发送请求。

### 操作步骤与预期结果

1. 用户点击「立即同步」。
2. 页面显示同步加载指示器。
3. 应用向配置的 WebDAV 服务端发送请求。
4. 如果只有加载状态而没有后端请求，则该功能点不满足要求。
