# WebDAV 恢复操作须在确认后发起网络请求

## 场景一：打开确认弹窗时不发起请求或恢复数据

### 场景概述

用户在 WebDAV 配置页点击「从云端恢复」后，应用必须先展示确认弹窗。仅打开该弹窗时不得连接 WebDAV 服务端，也不得开始下载或恢复数据。

### 操作步骤与预期结果

1. 用户进入 WebDAV 配置页，并配置可访问的 WebDAV 地址、账号、密码和同步密码。
2. 用户点击「从云端恢复」按钮。
3. 页面弹出恢复确认对话框。
4. 在用户尚未点击「继续」前，系统不向 WebDAV 服务端发送任何请求。

## 场景二：点击继续后才启动数据恢复流程

### 场景概述

用户在确认弹窗中点击「继续」后，应用才可以进入恢复流程，并向已配置的 WebDAV 端点发起请求，用于发现或获取云端备份数据。

### 操作步骤与预期结果

1. 用户点击「从云端恢复」按钮打开确认弹窗。
2. 用户在弹窗中点击「继续」。
3. 应用开始数据恢复流程。
4. 测试环境能够观察到应用向配置的 WebDAV 服务端发送请求。
