# WebDAV 恢复进度提示与实际操作保持一致

## 场景一：确认恢复后显示加载指示器

### 场景概述

用户点击「从云端恢复」并在确认弹窗中点击「继续」后，页面必须在恢复流程运行期间渲染 ArkUI `LoadingProgress` 加载指示器。

### 操作步骤与预期结果

1. 用户进入 WebDAV 配置页，并填写可访问的 WebDAV 配置。
2. 用户点击「从云端恢复」打开确认弹窗。
3. 用户点击「继续」确认恢复。
4. 页面显示 ArkUI `LoadingProgress` 加载指示器。

## 场景二：确认恢复后显示忙碌文案

### 场景概述

恢复忙碌状态必须包含「正在...」或「处理中...」一类的状态提示文字，提示用户当前正在执行云端恢复。

### 操作步骤与预期结果

1. 用户确认执行「从云端恢复」。
2. 页面进入恢复忙碌状态。
3. 页面显示操作进行中的状态提示。
4. 该文案在恢复操作进行期间可见。

## 场景三：确认恢复后向 WebDAV 服务端发送请求

### 场景概述

用户确认恢复后，应用必须向配置的 WebDAV 端点发送请求。仅改变 UI 文案或显示加载状态而不执行实际恢复操作，不满足该功能点。

### 操作步骤与预期结果

1. 用户在恢复确认弹窗中点击「继续」。
2. 页面显示恢复加载状态。
3. 应用向配置的 WebDAV 服务端发送请求。
4. 测试环境能够观察到该 WebDAV 请求。
