# 收货地址列表/新增/编辑功能

## 场景一

### 场景概述

用户进入收货地址管理页面，查看所有已保存的收货地址列表。每条地址显示联系人、电话和详细地址信息，并提供编辑和删除操作。用户点击底部"新增地址"按钮跳转到地址编辑页新建一条地址。

### 操作步骤与预期结果

1. 用户在个人中心或确认订单页进入收货地址列表页，系统加载并展示用户所有已保存的收货地址。
2. 每条地址显示联系人姓名、手机号、省市区和详细地址，默认地址顶部或旁边有"默认"标签标识。
3. 用户点击某条地址右侧的"编辑"图标，系统跳转到地址编辑页，并自动填入该地址的现有信息。
4. 用户点击某条地址右侧的"删除"图标，系统弹出确认对话框，提示"确认删除该地址吗？"。
5. 用户确认删除后，该地址从列表中移除，列表刷新展示剩余地址。
6. 用户点击页面底部"新增地址"按钮，系统跳转到新增地址页。

## 场景二

### 场景概述

用户在新增地址页面填写完整的地址信息，包括联系人、手机号、省市区（通过级联选择器选择）、详细地址，并可选择是否设为默认地址。填写完毕后点击"保存"按钮，系统校验表单并保存新地址。

### 操作步骤与预期结果

1. 用户进入新增地址页，页面标题显示"新增地址"，表单包含：联系人、手机号、所在地区、详细地址四个必填项，以及"设为默认地址"开关。
2. 用户点击"所在地区"输入框，系统弹出省/市/区三级联动级联选择器，用户逐级选择省、市、区后点击确认。
3. 所在地区字段自动填入选中的省市区文字（如"广东省 深圳市 南山区"）。
4. 用户填写联系人、手机号和详细街道地址，拨动"设为默认地址"开关将其设为默认。
5. 用户点击底部"保存地址"按钮，系统校验表单（若手机号格式不正确则提示"手机号格式不正确"），校验通过后提交新增请求。
6. 保存成功后，系统自动返回地址列表页，新增的地址出现在列表中。

## 场景三

### 场景概述

在确认订单页面中，用户以"选择模式"进入地址列表页，点击某条地址后系统自动携带所选地址信息返回确认订单页，无需额外确认操作。

### 操作步骤与预期结果

1. 用户在确认订单页面点击收货地址区域（切换地址），系统以"选择模式"打开地址列表页。
2. 地址列表展示所有已保存地址，用户浏览并选择目标地址。
3. 用户点击某条地址（而非编辑或删除按钮），系统立即携带该地址信息返回确认订单页，无需再点击其他按钮。
4. 确认订单页顶部的收货地址卡片更新为用户刚刚选择的新地址。

## 场景四

### 场景概述

用户在收货地址列表页点击某条已有地址右侧的"编辑"图标，进入的是"编辑地址"表单而不是空白的"新增地址"表单：联系人、手机号、所在地区、详细地址等字段均自动回填为该地址当前的真实信息，"设为默认地址"开关也保持与该地址一致的状态。用户只修改联系人姓名（不改动其余字段），点击底部"保存"按钮后，保存操作正常完成、不出现校验报错，页面自动返回收货地址列表页，列表恢复正常展示。

### 操作步骤与预期结果

1. 用户在收货地址列表页找到一条已有地址，点击其右侧的"编辑"图标（而不是点击地址整行或"新增地址"按钮）。
2. 系统跳转到地址编辑页，页面标题显示"编辑地址"；联系人、手机号、所在地区（省市区）、详细地址四个字段均已自动填入该地址当前保存的真实内容，"设为默认地址"开关也回显该地址原有的默认状态，而不是像新增地址页那样全部留空。
3. 用户在"联系人"输入框中修改姓名文字，其余字段保持不变。
4. 用户点击底部"保存"按钮，系统按编辑模式提交更新请求（不发送新增地址请求），保存过程中不重复处理点击操作、不出现"手机号格式不正确"等新增表单才会触发的校验错误。
5. 保存成功后，系统自动返回收货地址列表页，列表页面恢复正常展示（不停留在编辑表单、不显示网络错误或空态）。
6. 列表显示修改后的联系人；再次进入该地址的编辑页，修改后的姓名仍被正确回填，其余字段保持不变。
