# 0.9.3 版本信息、应用内隐私页与搜索提示统一

## 场景一：设置页显示 0.9.3 版本与完整入口

### 场景概述

应用发布版本升级为 0.9.3，用户从首页右上角更多菜单打开“设置”后，可在页面中核对当前版本，并同时看到隐私政策和问题反馈入口。页面底部保留云音汇项目信息，使版本和来源信息在同一个应用内页面中可见。

### 操作步骤与预期结果

1. 用户启动应用，点击首页右上角更多按钮并选择“设置”。
2. 设置页标题、“当前版本”、“隐私政策”和“问题反馈”行均正常显示。
3. 版本值显示“0.9.3 - 测试版”，与应用清单中的 versionName 0.9.3 一致。
4. 页面底部显示“云音汇 @Chenlvin”及 GitHub 项目名称。

## 场景二：隐私政策在应用内嵌页面打开并可返回

### 场景概述

隐私政策不再通过外部 `viewData` Want 交给其他应用。用户点击设置页的隐私政策说明文字后，应用导航到新增的 `PrivacyPage`，页面显示自身标题栏和 Web 内容容器。即使网络内容暂未加载，仍须显示应用内页面的标题，并支持正常返回。

### 操作步骤与预期结果

1. 用户在设置页点击“前往查看本软件的隐私政策”。
2. 前台应用仍为云音汇，新页标题显示“隐私政策”，页面内存在 Web 组件。
3. 用户执行返回操作后回到“设置”，0.9.3 版本值仍可见。

## 场景三：搜索框和空内容提交使用同一文案

### 场景概述

首页搜索框的占位文案由“请输入搜索词”统一为“请输入搜索内容”，并补充清晰的占位色和输入文字颜色。用户不输入任何内容直接点击搜索时，Toast 使用与占位文字相同的新提示，且不进入空搜索结果页。

### 操作步骤与预期结果

1. 用户重新返回或启动首页，搜索输入框显示“请输入搜索内容”。
2. 保持输入框为空并点击右侧搜索按钮。
3. 应用显示“请输入搜索内容” Toast，首页标识仍可见，不跳转到空关键词的搜索结果页。
