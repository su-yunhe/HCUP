# WebDAV 备份进度提示与实际操作保持一致

## 场景一：手动备份显示加载指示器

### 场景概述

用户点击「立即备份」后，WebDAV 配置页必须在备份操作仍在运行时渲染 ArkUI `LoadingProgress` 加载指示器。

### 操作步骤与预期结果

1. 用户进入 WebDAV 配置页，并填写可访问的 WebDAV 配置。
2. 用户点击「立即备份」按钮。
3. 页面进入备份忙碌状态。
4. 页面显示 ArkUI `LoadingProgress` 加载指示器。

## 场景二：手动备份显示忙碌文案

### 场景概述

备份期间，页面必须展示「正在...」或「处理中...」一类的状态提示文字，让用户能够区分正在工作和空闲状态。

### 操作步骤与预期结果

1. 用户点击「立即备份」。
2. 页面进入备份忙碌状态。
3. 页面显示操作进行中的状态提示。
4. 该文案在备份操作进行期间可见。

## 场景三：手动备份向 WebDAV 服务端发送请求

### 场景概述

加载状态必须绑定真实的 WebDAV 操作。备份流程在忙碌状态可见时，必须向配置的 WebDAV 端点发送请求。

### 操作步骤与预期结果

1. 用户点击「立即备份」。
2. 页面显示备份加载状态。
3. 应用向配置的 WebDAV 服务端发送请求。
4. 如果只出现加载状态而没有 WebDAV 请求，则该功能点不满足要求。
