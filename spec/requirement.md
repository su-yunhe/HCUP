# WebDAV 还原确认对话框

## 场景一

### 场景概述

用户在设置页面点击"从云端恢复"按钮，希望将本地数据还原为云端备份版本。由于该操作会覆盖本地数据，系统必须立即弹出第一层确认对话框，提醒用户本地未同步的学习记录将会丢失，并提供明确的取消和继续入口。

### 操作步骤与预期结果

1. 用户进入设置页面，找到 WebDAV 同步区域，点击"从云端恢复"按钮。
2. 系统立即弹出确认对话框，标题显示"⚠️ 从云端恢复"，内容提示本地未同步数据将丢失。
3. 对话框提供"取消"和"继续"两个按钮。
4. 在用户作出选择前，恢复流程停留在第一层确认阶段。

## 场景二

### 场景概述

用户点击"从云端恢复"后，在第一层确认对话框中改变主意，选择取消操作。系统不执行任何数据下载或覆盖操作，页面状态保持不变，用户数据不受影响。

### 操作步骤与预期结果

1. 用户进入设置页面，点击"从云端恢复"按钮。
2. 系统弹出第一层确认对话框，提示覆盖风险。
3. 用户点击"取消"按钮或直接关闭对话框。
4. 系统中止操作，不下载云端数据，不修改本地数据。
5. 页面回到初始状态，同步区域按钮恢复可点击状态。

## 场景三

### 场景概述

用户在误触"从云端恢复"按钮后，意识到操作错误，希望通过关闭弹窗来阻止还原流程。系统将弹窗关闭事件视为取消操作，与点击"取消"按钮效果等同，保证数据安全。

### 操作步骤与预期结果

1. 用户不小心触碰了"从云端恢复"按钮，弹出第一层确认对话框。
2. 用户通过系统手势或点击对话框外部区域将其关闭。
3. 系统捕获对话框关闭事件，将其视为用户取消操作。
4. 系统不执行任何下载或数据覆盖操作，流程终止。
