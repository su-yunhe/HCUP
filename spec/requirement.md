# 符号自定义完整功能（颜色选择器、渲染策略切换、信息栏水平滚动）

## 场景一

### 场景概述

用户在操作面板中看到颜色选择器组件，可以分别为符号的主色和副色选择系统预设颜色，符号渲染效果实时更新。

### 操作步骤与预期结果

1. 用户点击‘^’符号展开操作面板，看到三组颜色选择器（主色 / 副色 / 背景色）。
2. 点击颜色圆点，对应颜色应用到符号的 fontColor 列表。
3. 符号网格中的所有符号立即以新颜色重新渲染；旁边的胶囊按钮显示当前所选颜色的系统名称，方便复制代码。

## 场景二

### 场景概述

用户可以点击重置按钮将颜色选择器恢复为默认值，方便对比预设效果与自定义效果。

### 操作步骤与预期结果

1. 用户选择了自定义颜色后，想恢复默认。
2. 点击颜色选择器旁的重置图标（反向箭头符号）。
3. 主色恢复为 accent，副色恢复为 connected，背景色恢复为无（undefined）。

## 场景三

### 场景概述

用户在操作面板中看到渲染策略选择器，可以在 SINGLE（单色）、MULTIPLE_COLOR（多色）、MULTIPLE_OPACITY（多透明度）三种模式间切换，符号的渲染效果立即变化。

### 操作步骤与预期结果

1. 用户展开操作面板，看到渲染策略 SegmentButton（三段按钮）。
2. 符号网格中所有符号按新策略重新渲染；下方胶囊按钮显示当前策略名称（如 MULTIPLE_COLOR），方便复制对应 API 参数。

## 场景四

### 场景概述

符号数据中存在名称拼写错误（kmark_on_bookmark），修正为正确名称（bookmark_on_bookmark），防止按名称搜索或引用该符号时失败。

### 操作步骤与预期结果

1. 开发者或用户搜索"bookmark_on_bookmark"符号。
2. 修复前：符号名为 kmark_on_bookmark，搜索无结果。
3. 修复后：名称改为 bookmark_on_bookmark，搜索和引用均正常。

## 场景五

### 场景概述

用户选中一个名称较长的符号后，底部信息栏显示编号、字符、Unicode 和名称四个胶囊按钮，当总宽度超出屏幕时，用户可以水平滑动查看全部信息，不再有内容被截断的问题。

### 操作步骤与预期结果

1. 用户点击选中一个符号，底部信息栏显示对应的四个信息胶囊（No. / 字符 / Unicode / 名称）。
2. 当设备屏幕较窄或名称文本较长时，信息栏总宽度超出视口。
3. 用户可以左右滑动信息栏，所有胶囊完整可见；滑动结束后有弹簧回弹效果。

## 场景六

### 场景概述

信息栏改为可滚动容器后，横向滚动不影响纵向页面的主体布局，符号网格区域仍然占据主体空间正常显示。

### 操作步骤与预期结果

1. 用户同时进行符号网格浏览和信息栏内容查看。
2. 向左右滑动信息栏时，触发水平 Scroll 滚动，不干扰纵向 WaterFlow 的滑动。
3. 搜索栏和符号网格的布局位置不受信息栏宽度变化影响。
