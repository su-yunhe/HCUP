# 商品分类页面完整功能（搜索/筛选/排序/布局切换/分页加载）

## 场景一

### 场景概述

用户进入商品分类页面浏览商品，页面顶部嵌入搜索框，下方筛选排序栏提供"筛选"下拉菜单和"排序"下拉菜单，商品列表支持网格与列表两种布局模式切换，并支持下拉刷新和上拉加载更多。

### 操作步骤与预期结果

1. 用户通过点击分类或搜索结果进入商品分类页，页面标题区域显示可输入的搜索框，用户可直接修改搜索词再次搜索。
2. 搜索框下方展示筛选排序栏，左侧为"筛选"下拉按钮，中间为"排序"下拉按钮，右侧为布局切换图标。
3. 商品列表默认以两列网格形式展示，每个商品格显示主图、名称和价格。
4. 用户点击右侧布局切换图标，商品列表切换为单列列表布局，再次点击切换回网格布局。
5. 用户向下滚动到列表底部，系统自动加载下一页商品数据并追加到列表末尾。

## 场景二

### 场景概述

用户通过筛选功能对商品进行多维度过滤，包括按分类标签筛选和设置价格区间。用户可先在筛选面板中调整条件，再统一确认应用，也可一键重置为默认条件。

### 操作步骤与预期结果

1. 用户点击筛选排序栏中的"筛选"按钮，页面弹出下拉筛选面板，面板内展示价格区间输入和多个分类标签组。
2. 用户在价格区间中输入最低价和最高价（如50~200），两者之间有横线分隔。
3. 用户点击某个分类标签（如"运动户外"），该标签高亮显示（边框变色），可多选。
4. 筛选面板底部显示"重置"和"确认"两个按钮，用户点击"确认"，面板关闭，商品列表按筛选条件重新加载。
5. 用户再次打开筛选面板，点击"重置"按钮，所有筛选条件清空，再点击"确认"，商品列表恢复全量展示。

## 场景三

### 场景概述

用户通过排序下拉菜单对商品列表进行排序，支持综合排序、价格升降序和销量升降序，选择不同排序方式后列表立即重新加载。

### 操作步骤与预期结果

1. 用户点击筛选排序栏中的"排序"下拉按钮，展开排序选项列表，包含：综合排序、价格由低到高、价格由高到低、销量由低到高、销量由高到低。
2. 用户选择"价格由低到高"，下拉菜单关闭，排序按钮标题更新为当前选中的排序方式名称。
3. 商品列表刷新，商品按价格从低到高重新排列展示。
4. 用户再次打开排序菜单，切换为"销量由高到低"，商品列表再次刷新并按销量降序排列。
5. 用户选择"综合排序"，商品列表恢复服务端默认排序。
